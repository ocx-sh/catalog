# Theme port — functional defect list

Scope: functional parity audit of the OLD 0.5.3 VitePress + Vue theme (read-only checkout of `main`) against the NEW Astro + `@ocx-sh/theme` port on `hex/plan-ocx-theme-port`. Each row is a behaviour the OLD UI had and the NEW one lacks or weakens. It was found by a per-unit audit and then re-verified by a second pass against the code, the ADR (`.claude/artifacts/adr_ocx_theme_port_2026-10-07.md`) and the upgrade guide (`docs/src/content/docs/how-to/upgrade-to-0-6.md`). Duplicate reports of one behaviour are merged into one row with all evidence kept, and where verifiers rated a merged row differently the highest verified severity is shown. Most findings come from reading code and CSS. Nothing was rendered in a browser unless a row says so. Totals: 191 rows. Severity: 1 blocker, 43 major, 128 minor, 19 none. Status (closed out at the 0.6.0 fix pass): fixed or removed-by-decision, except one named residual (D-165).

Status meanings: missing = OLD behaviour has no NEW counterpart; degraded = a weaker counterpart exists; removed-by-decision = the ADR or upgrade guide records the removal (see the last section); fixed = the port now has a counterpart, pinned by a test; residual = deliberately left, with a `Residual:` reason in the Detail cell. "Old" paths are relative to the repo root of the 0.5.3 checkout, "New" paths relative to this repo.
